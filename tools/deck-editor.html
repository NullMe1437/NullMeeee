選擇要編輯的簡報

已讀取整個資料夾，請選擇其中一個 HTML。

儲存與顯示設定

預設不備份；開啟後會在原 HTML 旁建立 HTMLeditor-backups 資料夾。單檔開啟時，第一次存回會使用原檔所在資料夾。

插入表格

先點選要插入的位置，再設定表格大小。表格會插入目前文字區塊。

　

幾個字，直接在頁面上改。

  1. 開啟：只有一個檔案用「開啟 HTML」。圖片、CSS 在旁邊時用「開啟資料夾」，選含有 HTML 的最上層資料夾。
  2. 編輯：點文字或拖選文字，再使用工具列。下方箭頭及頁次選單可翻頁；文字內的方向鍵用來移動游標。清單按 Enter 新增下一項，Shift+Enter 在同一項換行。「清除格式」會移除選取文字的粗體、顏色、底線等行內格式；引用段落可用「一般段落」切回。Ctrl+Z 撤銷、Ctrl+Y 重做。插入圖片會將新圖片內嵌到 HTML，因此會增加檔案大小。
  3. 檢查：按「放映檢查」，原本的翻頁鍵和互動便恢復；按「回到編輯」留在同一頁。
  4. 儲存：「存回原檔」會使用開啟時的原檔 handle 與原父資料夾；預設不建立備份。到「設定」開啟備份後，才會在原檔旁建立 HTMLeditor-backups 資料夾並先備份再覆寫。另存時請避開原檔名。

顯示：右上角可切換日間／夜間模式；選擇會自動記住。到「設定」可開啟或關閉存回前備份。

存不進去：未授權、檔案唯讀、原檔被其他程式修改、瀏覽器限制寫入，均可改用「另存新檔」。資料夾版的另存檔必須放回原 HTML 同一層，圖片和 CSS 不會複製。

請使用 Edge。其他瀏覽器或一般 HTTP 網站可能只有「下載另存」功能。支援本工具已辨識的 SLIDES 資料陣列與一般 HTML 文字區塊；canvas 文字、複雜框架產生的內容可能無法編輯。工具列只能編輯來源中已辨識的文字區塊，目前不支援可自由拖曳、獨立於原文字區塊的 PPT 式文字框。未加框的圖表標籤維持原樣。
